# Flowdesk Interface & Settings

This repo contains a lightweight, smooth UI with two static pages:

- `index.html` – Hauptinterface mit Dashboard, Quick Actions und CTA.
- `settings.html` – Einstellungen für Theme, Akzentfarbe, Motion und Pulse.

## Lokal ansehen

```bash
python -m http.server 8000
# öffne anschließend http://localhost:8000
```

## Auf GitHub prüfen

Stelle sicher, dass du die Dateien auf der Branch `work` siehst. Falls dein Standardbranch anders heißt, wechsle auf `work` oder merge die Änderungen dorthin, damit GitHub sie anzeigt. Für GitHub Pages genügt das Root-Verzeichnis; richte Pages auf dieser Branch ein oder verschiebe die Dateien in deine veröffentlichte Branch.
